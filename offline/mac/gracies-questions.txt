# QUESTION 16
Q: Someone stops using marijuana, then starts using it again. Which health term describes this?
A: Return to use, sometimes called relapse
B: Tolerance
C: Withdrawal
D: Intoxication only
ANSWER: A
SOURCE: https://medlineplus.gov/ency/patientinstructions/000796.htm
CITATION: A.D.A.M., Inc. (n.d.). Substance use - marijuana. In A.D.A.M. medical encyclopedia. MedlinePlus. Retrieved November 5, 2026, from https://medlineplus.gov/ency/patientinstructions/000796.htm
EXPLANATION: Starting to use marijuana again after a period without it is a return to use; relapse is another term for it.
